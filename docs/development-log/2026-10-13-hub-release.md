# Publishing the model to the Hugging Face Hub

**Date:** 2026-10-13
**Status:** Done
**Branch:** `feat/hub-release`

## Goal
Publish the best fine-tuned model with an honest model card built from measured results, then load it back from the Hub as a stranger would and confirm it reproduces the saved numbers.

## Decisions
- **Model published:** DistilBERT trained with standard cross-entropy (unweighted). Reasons: higher test accuracy (0.9265 vs 0.9225) and higher validation macro-F1 (0.9146 vs 0.9129), which is the fair selection criterion. Test macro-F1 is slightly lower (0.8873 vs 0.8903), but all differences are within single-seed noise. The class-weighted trade-off is described in the card.
- **Repository:** `BHARATHKUMAR0409/emotion-distilbert`, public.
- **Authentication:** browser (OAuth) login with `hf auth login`. The token lives in the user profile cache (`C:\Users\91936\.cache\huggingface\`), outside the repository, so it cannot be committed. No token was typed into any file or chat.
- **Model card:** generated by `src/hub/model_card.py` from the saved result files (`results/*.json`), so card numbers cannot drift from measured numbers.

## Files created
- `src/hub/model_card.py`: builds the model card from saved results
- `src/hub/verify.py`: loads the published model from the Hub, scores the full test set, runs example sentences
- `tests/test_hub.py`: 3 tests (valid front matter, numbers match saved results, limitations and license present)

## 1. Upload
Five files uploaded (268 MB): `model.safetensors`, `config.json`, `tokenizer.json`, `tokenizer_config.json` and the model card. The browser-login token had write access, so no separate write token was needed.

Model page check (screenshots reviewed): title, tags (Text Classification, Transformers, Safetensors, dair-ai/emotion, English), base model tree, 67M parameters, F32 tensor type, and evaluation results (accuracy 0.926, macro-F1 0.887, self-reported, rounded to 3 decimals by the Hub), and the usage snippet all rendered. The Hub labels the model-index block "Eval Results (legacy)" and added a "text-embeddings-inference" tag by itself. Neither is an error.

## 2. Load-back verification
The published model was loaded from the Hub through `transformers.pipeline` (fp32, GPU, batch 64, `max_length=64`) and scored on the full test set.

| Check | Value |
|---|---|
| Labels | sadness, joy, love, anger, fear, surprise |
| Test accuracy via Hub pipeline | 0.927 (1,854 of 2,000) |
| Saved local result | 0.9265 (1,853 of 2,000) |
| Difference | 0.0005, exactly one example |

The first version of the check required an exact match and reported `False`. The likely explanation, which was not isolated, is that the pipeline runs in fp32 while the training-time evaluation used fp16 autocast, flipping one borderline prediction. The check was changed to "within 0.001", which tests the claim actually made. The model card and README keep the training-time number (0.9265).

Example predictions (six sentences written by me, a sanity check and not a result):

| Sentence | Top 2 |
|---|---|
| i feel so helpless right now | sadness 0.823, fear 0.162 |
| i am so happy that i got the job | joy 0.988, anger 0.005 |
| i cannot believe this just happened, i did not see that coming | fear 0.605, sadness 0.162 |
| i am furious about how they treated me | anger 0.991, fear 0.004 |
| i am terrified of what comes next | fear 0.992, anger 0.003 |
| i feel so close to her and care about her deeply | love 0.946, joy 0.036 |

Five of six look right. The sentence meant to express surprise was predicted as fear (surprise not in the top two), which fits the measured weakness on that class (recall 0.7121, with 13 of 66 test surprise examples sent to fear). One sentence proves nothing on its own.

## 3. The license mistake
The first card was published with `license: apache-2.0`, copied from the base model's license, before the dataset's license had been checked. After publishing, the dataset page was inspected: its license field is "other" and its Licensing Information says the dataset "should be used for educational and research purposes only". The published card was therefore wrong.

Fix: the card now uses `license: other` with `license_name: educational-and-research-use-only`, has a "License and intended use" section, notes that the base model is Apache-2.0, says the author is not a lawyer, and cites the dataset (Saravia et al., 2018, CARER, EMNLP). The README alone was re-uploaded. The model was public with the wrong license for a few minutes. The test now asserts the license text and the citation, so it cannot regress.

Lesson: check the training data's license before choosing the model's license, not after publishing.

## Limitations
- The published numbers come from one training run with one seed.
- The Hub copy scores 0.927 and the training-time number is 0.9265 (one example, fp32 vs fp16).
- Whether a model trained on this dataset inherits its "educational and research" restriction is a legal question that was not resolved. The card chooses the cautious wording.
- The six example sentences are a sanity check, not an evaluation.
- The model was not evaluated outside English tweets in a first-person style.
