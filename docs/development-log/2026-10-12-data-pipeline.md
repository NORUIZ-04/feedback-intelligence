# Data pipeline and dataset analysis

**Date:** 2026-10-12
**Status:** Done
**Branch:** `feat/data-pipeline`

## Goal
Build a reproducible data pipeline for `dair-ai/emotion` and measure the dataset before any model is trained, so that later results can be interpreted correctly.

## Dataset
Short English text (tweets) labelled with one of six emotions. The Hub dataset ships with predefined train, validation and test splits, which are kept as they are.

## Design decisions
- Validation and test are only whitespace-normalized, never filtered, so scores remain comparable with published results.
- The train split is additionally filtered for (1) texts that appear with conflicting labels, (2) exact duplicates, and (3) texts that also appear in validation or test. Conflicting labels are label noise and leakage would inflate test scores.
- Cleaned splits are written to `data/processed/` as parquet. This folder is git-ignored because it is fully reproducible from the script.
- All numbers are saved to `results/data_profile.json` through the shared `save_metrics` helper; the markdown below is generated from the same data.

## Files created
- `src/data/loader.py`: loads the dataset and label names
- `src/data/cleaning.py`: normalization and train-only filtering
- `src/data/analysis.py`: profiling and markdown rendering
- `src/data/plots.py`: class distribution and text length plots
- `src/data/prepare.py`: command-line entry point
- `tests/test_data.py`: unit tests for cleaning and profiling
- `configs/train.yaml`: added `data.processed_dir`

## Key findings
- The train split has 15,923 rows after cleaning (77 of 16,000 removed: 60 conflicting labels, 1 duplicate, 16 also present in validation or test).
- Classes are imbalanced: joy is 33.54% of train, surprise only 3.54% (imbalance ratio 9.47).
- Always predicting the majority class (joy) would score about 33.5% accuracy on train-like data, which is the floor any model must beat.
- Texts are short: mean 19.18 words, 95th percentile 41, maximum 66.

## Notes for the modelling work
Macro-F1 and per-class F1 are reported alongside accuracy so that small classes are not hidden by large ones. Class weighting will be tested because of the 9.47 imbalance ratio. The text length statistics set the tokenizer `max_length`, which will be confirmed by measuring token lengths.
